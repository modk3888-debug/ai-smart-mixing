# AI 스마트 믹싱 시스템

부정형 내화물(캐스터블) 믹싱 작업을 대상으로 작업환경과 배합 조건을 분석하고, 회차별 권장 작업조건을 제공하는 웹 시스템입니다.

## 1. 주요 목적

- 작업장 온도·습도와 내화물 종류 확인
- 총 투입량을 기준으로 사이클·차수별 작업조건 관리
- 권장 수분량, 믹싱시간, 호퍼 대기시간, 지연제 사용 여부와 위험도 표시
- 작업자가 추천값을 검토하고 필요한 경우 수정
- 작업일지와 배합이력에 실제 작업조건과 특이사항 기록
- 실제 작업 결과가 축적되면 XGBoost 모델 재학습에 활용

## 2. 시스템 흐름

```text
환경값·작업조건 입력
        ↓
XGBoost 추천 API 호출
        ↓
회차별 권장 수분량·믹싱시간·호퍼 대기·위험도 계산
        ↓
작업자 검토 및 필요 시 수정
        ↓
추천 조건 승인 또는 작업자 조건 승인
        ↓
작업일지 저장
        ↓
배합이력 기록 및 향후 모델 재학습 데이터 축적
```

## 3. 화면 구성

### 공정 순서

전체 작업 흐름과 AI 추천 역할을 설명합니다.

### 대시보드

- 작업명 및 내화물 종류
- 작업장 온도·습도 입력
- 총 투입량과 사이클·차수별 조건
- 권장 수분량
- 믹싱시간
- 호퍼 대기시간
- 지연제 사용 여부
- 위험도
- 추천 조건 승인
- 작업자 수정값 표시

### 작업일지

- 차수별 실제 작업조건
- 차수별 특이사항
- 작업자 정보
- 작업 결과
- 추천 조건 또는 작업자 조건 전달 결과

### 배합이력

- 저장된 작업 목록
- 작업명별 상세 작업내용
- 회차별 수분량·믹싱시간·호퍼 대기·지연제 사용 여부
- 차수별 특이사항
- 작업 결과와 저장 이력

## 4. AI 모델

백엔드에는 XGBoost 기반 믹싱 추천 모델이 연결되어 있습니다.

### 입력값

- 작업장 온도
- 상대습도
- 투입량
- 사이클 번호
- 차수 번호
- 내화물 종류

### 출력값

- 권장 수분량
- 권장 믹싱시간
- 예상 호퍼 대기시간
- 지연제 사용 여부
- 위험도
- 모델 검증 성능과 현재 조건 범위를 반영한 추천 신뢰도

### 모델 관련 API

- `GET /health` : 서버 상태 확인
- `GET /model/status` : 모델 상태와 검증 결과 확인
- `POST /model/recommend` : 현재 조건의 추천값 계산
- `POST /model/fit` : 검증된 작업일지 데이터로 모델 재학습
- `POST /analyze` : 업로드 이미지 분석
- `POST /learning-images` : 학습 데이터 기록
- `DELETE /learning-images/{record_id}` : 학습 데이터 삭제

## 5. 추천값 수정 처리

- AI 추천값 그대로 저장하면 `AI 추천 적용`으로 표시합니다.
- 작업자가 수분량·믹싱시간·호퍼 대기·지연제 사용 여부를 바꾸면 `작업자 수정`으로 표시합니다.
- 수정값은 파란색으로 표시합니다.
- 수분량은 `26.0L`처럼 단위와 소수점 형식을 유지합니다.
- 작업자가 다시 AI 추천값과 같게 되돌리면 `AI 추천 적용`으로 복원합니다.

## 6. 백엔드 실행

```powershell
cd ai-service
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```

프론트엔드 HTML은 백엔드가 제공하는 API를 호출해 추천값을 표시합니다.

## 7. 현재 데이터와 운영상 주의점

현재 포함된 초기 데이터는 시스템 시연과 기능 검증을 위한 데이터입니다. 실제 현장 운영용 모델로 사용하려면 실제 작업일지에 다음 결과를 지속적으로 기록해야 합니다.

- 실제 수분 투입량
- 실제 믹싱시간
- 실제 호퍼 대기시간
- 지연제 사용 여부
- 작업 결과(정상, 경화 의심, 재작업, 폐기 등)
- 작업자 특이사항

충분한 실제 라벨 데이터가 쌓인 뒤 모델을 재학습하고, 별도 검증 데이터로 성능을 확인해야 현장 적용 수준의 추천 신뢰도를 판단할 수 있습니다.
